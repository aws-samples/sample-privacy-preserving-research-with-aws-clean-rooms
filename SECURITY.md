# Security

## Reporting a security issue

If you think you've found a potential security issue in this project, report it to AWS/Amazon Security through the [AWS vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/). Please do **not** open a public GitHub issue or pull request for it.

## Scope

Airlock is demo code that runs on synthetic data. Its settings are hardened for a demo only; see [Demo hardening only](README.md#demo-hardening-only) in the README for what to change before you adapt it to real data.
